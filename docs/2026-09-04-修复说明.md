# 山外山（知乎炼金术）本轮修复说明 — 2026-09-04

给队友看的：这一轮我（AI 助手）把线上反馈的 6 个问题全修了一遍，并定位到一个隐藏大坑。

## 一句话背景
用户走了一遍「提问 → 看山头冲突 → 自测辨向 → 行动地图」全流程后，反馈了 6 个具体问题。我先在本地桌面副本改代码、构建、重启服务，并用真实接口探针验证每一项都生效了，才同步到这个 git 仓库。

## 根因（最重要的发现）
用户之前看到的「逆天名字」「每题答案都一样」，其实**主要不是模型乱编，而是直答接口 20 秒超时、频繁走了兜底路径（realDataFallback）**：
- 兜底路径里角色名全被填成「知乎答主」，于是自测题每题选项都变成"只在「知乎答主」的局部处境…"，看起来每题都一样；
- 兜底还会把搜索标题当角色名。

**修复**：把直答超时放宽到 40 秒、预算 44 秒、前端等待 70 秒，现在 LIVE 直答能稳定跑通，不再总掉兜底。

## 6 项修复
1. **② 逆天名字**：收紧 prompt 禁止把搜索标题/问句当角色名；兜底路径改成「一线从业者 / 资深从业者 / 行业观察者…」等有区分度的派系标签。探针实测角色名变成「成功从零转行的数据分析师」这类正常人设。
2. **③ 知乎作为主体**：原来 1/4 上限是按"目标 10 条"算的，知乎结果少时全网反占一半（用户原话"知乎少、全网多"）。改成按"实际展示条数"限全网占比，确保知乎永远占主体。探针实测来源 4 知乎 + 2 全网。
3. **④ 参考标题**：来源卡片原来把原始搜索长标题（如「找靠谱运动康复机构…」）原样展示。现在清洗：去掉" - 知乎"尾巴、去掉 SEO 尾巴、超 36 字截断。
4. **⑤ 自测题不雷同**：收紧 prompt，强制每题选项引用各派真实立场、禁止套同一套模板文案。探针实测 5 题选项各异。
5. **⑥ 行动地图结构对齐**：后端 prompt 原来是旧的 `task/why`，前端要新的"假设/去做/坚持/收手"结构，两端对不上。统一成 `when / hypothesis / action / goSignal / stopSignal / role` 六字段。
6. **⑥ 行动地图可动态重生**：新增 `POST /api/actions` 接口 —— 把用户"最信哪一派 + 哪些盲区"喂给模型，第二趟重新生成行动地图（先验证判断、再下结论）。前端行动页新增「按我刚答的辨向，重做一份行动地图」按钮。探针实测：主导派给 2 条验证、盲区给 2 条补全。

## 怎么验证
本地 `node server.mjs`，浏览器开 `localhost:3000`：
- 输入一个真实问题（如"30岁转行做数据分析靠谱吗"），走完流程；
- 看冲突山头角色名是否正常、来源是否知乎占多数、自测题选项是否各异、行动地图是否带"假设/去做/坚持/收手"；
- 答完自测后点「按我的辨向结果生成脚下三步」→ 行动页点「重做一份行动地图」验证动态重生。
