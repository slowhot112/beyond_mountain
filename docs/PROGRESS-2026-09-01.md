## 三、新增内容与实现功能

### 1. 结果页信息架构调整

- 新增「炼金包」总览页，② 主流观点 / ③ 判断力自测 / ④ 行动地图 作为三个独立入口分别进入。
- 顶部逻辑链扩展为五个节点（处境卡 → 炼金包 → 主流观点 → 判断力自测 → 行动地图），支持任意跳转。
- 各模块页提供返回总览入口；未完成自测时，行动地图入口保持锁定并给出提示。

### 2. 来源文章去重

修复同一篇知乎文章被多个观点重复引用的问题。根因为知乎返回的同一文章标题末尾标点不一致（半角与全角问号），原去重逻辑按原始标题比对，未能识别为同一篇。

现采用归一化标题判重（去除标点与空白），并在三个层面设置去重：

- 搜索层：按归一化标题合并，保留赞数最高的一条；
- 角色来源分配层：不同角色强制分配不同来源，来源不足时宁可减少引用也不重复；
- 前端渲染层：再次按归一化标题去重，作为兜底。

角色数量超过可用独立来源数时自动收窄。

### 3. 内容不足时的处理

相关高赞讨论不足时返回 `lowConfidence` 标记，页面显示对应提示，说明内容来自相近主题，并引导用户关注前提条件是否匹配，而非直接套用结论。

### 4. 判断力自测

- 选项改为横向排布；每题增加「其他（自己写）」选项，支持填写自定义立场并计入统计。
- 题干默认折叠显示，超长可展开。
- 完成后提供跳转行动地图的入口。

### 5. 行动地图

- 按处境卡填写的时间压力分档生成任务：

| 时间压力 | 任务粒度 |
|---|---|
| 一周内 | 2 小时内 / 今天下班前 / 本周结束前 |
| 一个月左右 | 今天 / 本周内 / 本月结束前 |
| 三个月以上 | 本周内 / 本月内 / 三个月内 |
| 未填写 | 首条任务为明确时间窗口 |

- 与当次自测结果打通：顶部显示立场倾向与盲区，并给出对应的行动顺序建议。

### 6. 兜底内容治理

直答调用失败时的兜底内容由此前的整段原文改为短摘要呈现，论点、题干、选项均设置长度上限。角色名称改用观点摘要，作者信息调整为副标题。

### 7. 质量保障

新增 `scripts/fallback-check.mjs`，共 16 项回归断言，覆盖题干长度、选项结构与覆盖度、来源去重、低置信标记、四种时间压力分档等。该脚本无外部依赖，不消耗接口额度。
